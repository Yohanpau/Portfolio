# Portfolio

Yohan's portfolio. React + Vite + Tailwind CSS v4, deployed to GitHub Pages by GitHub Actions.

```sh
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

- Content: `src/data.js` (replace every `[bracketed]` placeholder before publishing)
- Resume PDF: put it at `public/resume.pdf`
- Resume text: `resume/RESUME.md`
- Deploy: push to `main`, after setting **Settings → Pages → Source: GitHub Actions** once
